### Hi, I'm Mike

I build **[OpenRig](https://github.com/mvschwarz/openrig)**, an open-source tool that turns coding agents like Claude Code and Codex into a persistent team. You talk to a lead agent; specialists share project knowledge and hand work to each other, each in its own terminal, and you can step into any conversation.
